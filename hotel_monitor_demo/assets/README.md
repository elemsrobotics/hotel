# Hotel lobby cover

`hotel-lobby.png` was generated with the built-in imagegen tool for this demo. It depicts a fictional interior and is decorative, not a photograph of an actual property.

Prompt: Photorealistic architectural editorial photograph of a modern boutique hotel lobby, warm ivory plaster, pale oak, a curved cream sofa, travertine reception, an olive tree, tall windows and soft morning sunlight. Understated luxury, neutral colors and dark forest green accents. Wide composition, architecture on the right and simpler wall on the left for a text overlay. No people, text, logos or watermarks.
